# 🚀 Aether OpenAI Proxy Server

一個基於 .NET 8 打造的高效能後端服務， 整合 OpenAI
即時語音聊天、WebSocket 雙向通訊、JWT 驗證、OneSignal 推播， 並透過
Azure YAML Pipeline 自動化部署。

------------------------------------------------------------------------

## 🏗 系統架構 - 四層架構設計

本專案採用乾淨且可維護的四層架構：

    Controller
        ↓
    Service
        ↓
    Repository
        ↓
    DataAccess

### 1️⃣ Controller Layer

-   負責接收 HTTP / WebSocket 請求
-   驗證輸入資料
-   呼叫 Service 處理業務邏輯
-   回傳標準化 API Response

### 2️⃣ Service Layer

-   核心商業邏輯
-   串接 OpenAI
-   管理推播流程
-   控制聊天流程與權限驗證

### 3️⃣ Repository Layer

-   抽象資料存取邏輯
-   封裝 MongoDB 操作
-   提供資料快取，增進系統效率

### 4️⃣ DataAccess Layer

-   直接與 MongoDB 連線
-   管理資料模型與索引
-   處理資料庫連線與設定

------------------------------------------------------------------------

## 🌐 通訊方式

### ✅ RESTful API

-   使用標準 HTTP 動詞 (GET / POST / PUT / DELETE)
-   JSON 格式回傳
-   搭配 JWT 驗證機制

### ✅ WebSocket 即時連線

-   支援雙向即時通訊
-   用於語音聊天串流
-   即時傳輸文字與語音資料

### ✅ Middleware 機制

-   JWT 驗證 Middleware
-   錯誤處理 Middleware
-   日誌 Middleware
-   權限與角色控制 Middleware

## 🎙 OpenAI 即時語音聊天 Proxy Server

本專案為一個 Proxy Server，負責：

-   轉發前端請求至 OpenAI
-   處理語音串流資料
-   管理對話 Session
-   控制每日使用配額
-   記錄聊天紀錄至 MongoDB

支援：

-   即時語音輸入
-   即時語音回傳
-   多輪對話管理
-   WebSocket 串流模式

------------------------------------------------------------------------

## 🔔 OneSignal 推播整合

支援：

-   群播推播
-   排程推播

用途：

-   系統通知
-   聊天提醒
-   使用額度通知
-   重要事件提醒

## 🚨 聊天異常偵測與警示系統

本專案內建聊天內容監測機制，用於提升平台安全性與風險控管能力。

功能包含：

-   檢查聊天訊息是否含有需要警示內容
-   風險分數計算機制
-   訊息標記並保存至 MongoDB
-   發送警示通知
